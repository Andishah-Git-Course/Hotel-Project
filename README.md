# 🏨 Hotel Project

A simple and responsive hotel website built with **HTML and CSS**.

This project was created as a front-end practice project to improve my skills in building website layouts, styling, positioning, navigation, forms, and working with images and icons.

## 🌐 Live Demo

**[View the Hotel Project](https://andishah-git-course.github.io/Hotel-Project/)**

## ✨ Features

* 🏨 Hotel landing page
* 🛏️ Room section with different room types
* 📋 Hotel booking form
* 📍 About section with location information
* 🖼️ Image-based destinations section
* 📱 Responsive layout
* 🔗 Navigation bar
* 🎨 Custom CSS styling
* ⭐ Font Awesome icons

## 🛠️ Technologies

* HTML5
* CSS3
* Font Awesome

The main purpose of this project was to practice and strengthen my **HTML and CSS** skills by creating a complete hotel website from scratch.

Through this project, I practiced:

* HTML page structure
* CSS layout and positioning
* Navigation bars
* Forms and inputs
* Flexbox
* Images and image effects
* Icons
* Responsive design
* Organizing project assets
